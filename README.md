# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

## 💻 1. 유틸리티 앱

### 앱 이름

Git Command Finder

### 배포 링크

https://gemini.google.com/share/8c2c53ba0de5

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 개발자들이 복잡한 Git 명령어를 사용할 때 발생할 수 있는 실수를 줄이고, 명령어 실행 후의 결과를 직관적으로 이해하기 어려운 점을 해결하고자 했습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 우아한테크코스 과정이나 개인 프로젝트에서 복잡한 브랜치 전략을 관리해야 할 때 주로 사용할 계획입니다. 특히 새로운 Git 명령어를 시도하기 전 결과를 미리 시각적으로 확인하는 용으로 예정입니다.

### 주요 기능

- 사용자가 처한 상황(예시: "마지막 커밋 메시지를 수정하고 싶어", "특정 브랜치의 커밋 하나만 가져오고 싶어")을 입력하면 그에 맞는 정확한 Git 명령어를 안내합니다.
- 명령어를 실행했을 때 Git 브랜치 구조가 어떻게 변하는지 Mermaid.js를 활용해 인포그래픽으로 보여줍니다. 이를 통해 명령어의 효과를 시각적으로 미리 이해할 수 있습니다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - Gemini AI를 활용한 Git 명령어 추천 및 시각화 기능을 탑재했습니다. 사용자가 현재 상황을 설명하면 적절한 Git 명령어를 제안하고, 실행 전후의 상태를 Mermaid.js를 이용해 그래프 형태로 미리 보여줍니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 복잡한 Git 작업을 수행하기 전 그 결과를 시각적인 인포그래픽으로 미리 확인하게 함으로써, 명령어 오용으로 인한 실수를 방지하고 Git 워크플로우에 대한 이해도를 높이는 길잡이 역할을 합니다.

## 📚 3. 학습 앱

### 앱 이름

Switch Tailwind

### 배포 링크

https://gemini.google.com/share/c1a08a09d416

### 이 앱을 만든 이유

- 어떤 문제/불편함을 해결하려고 했나요?
  - 기존의 CSS 문법에 익숙한 개발자들이 Tailwind CSS의 독특한 클래스 기반 방식에 적응하는 데 겪는 어려움을 해결하고자 했습니다. 매번 공식 문서를 찾아보지 않고도 직관적으로 CSS 속성이 Tailwind 클래스로 어떻게 대응되는지 익히고, 실무에서 자주 쓰이는 유틸리티 클래스를 빠르게 습득할 수 있도록 돕기 위해 만들었습니다.
- 본인이 이 앱을 언제, 어떻게 사용할 건가요?
  - 프로젝트에 Tailwind CSS를 도입하거나, 특정 CSS 속성을 Tailwind로 어떻게 구현해야 할지 영감이 필요할 때 사용할 예정입니다. 학습 탭의 인포그래픽을 보며 개념을 정리하거나, 퀴즈와 실습을 통해 실력을 점검하며 생산성을 높이는 도구로 활용할 것입니다.

### 주요 기능

- 인포그래픽을 활용하여 CSS 문법이 Tailwind CSS로 변환되는 규칙을 한눈에 보여줍니다. 특히 반응형 디자인과 같은 기본 문법을 시각적으로 제공하여 구조적인 이해를 돕습니다.
- 주어진 CSS 코드를 Tailwind CSS로 변환하는 연습 문제를 풀거나, 실습 에디터에서 직접 코드를 입력하고 즉각적인 피드백을 확인하며 실전 감각을 익힐 수 있습니다.

### AI 기능 (해당되는 경우)

- 어떤 AI 기능을 추가했나요?
  - AI 변환기 기능과 퀴즈/실습 탭에서의 문제 제출 기능을 추가하였습니다.
- AI 기능이 앱에서 어떤 역할을 하나요?
  - 사용자가 표준 CSS 문법이나 원하는 스타일을 자연어로 입력하면, AI가 이를 최적화된 Tailwind CSS 클래스 조합으로 즉시 변환해 줍니다. 단순한 변환을 넘어 학습자가 이해하기 쉽게 변환 규칙에 대한 설명을 덧붙여주는 학습 보조 역할을 수행합니다.
    또한, 퀴즈와 실습 문제를 그때그때 다르게 제출하여 사용자의 학습을 돕습니다.
